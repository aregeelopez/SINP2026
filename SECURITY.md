# Security Policy

## Supported Versions

SINP2026 is currently under active development. Security updates are provided for the latest released version.

| Version | Supported |
| ------- | --------- |
| Latest release | ✅ |
| Older releases | ❌ |

## Reporting a Vulnerability

If you discover a security vulnerability in SINP2026, please report it responsibly by emailing **aregeelopez@outlook.com**.

Please include:

- A description of the vulnerability
- Steps to reproduce the issue
- The potential impact
- Any suggested mitigation or fix

Do not publicly disclose security issues until they have been reviewed and addressed.

## Response Process

After receiving a report:

1. The issue will be reviewed and investigated.
2. If confirmed, reasonable steps will be taken to address the vulnerability.
3. Updates will be provided when appropriate.
4. If the issue is declined, an explanation will be provided when possible.

## Privacy Considerations

SINP2026 is designed to support interpreter note-taking workflows. Users should avoid entering unnecessary personally identifiable information (PII), protected health information (PHI), or confidential client information unless appropriate safeguards are in place.

Security reports involving data exposure, privacy risks, authentication issues, or unsafe handling of sensitive information are especially important.
